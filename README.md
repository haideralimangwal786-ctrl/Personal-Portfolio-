# Haider Ali - Personal Portfolio & Digital Showcase

An ultra-animated, futuristic personal portfolio website built for **Haider Ali** (MERN Stack Developer, Canva Graphic Designer, & MS Excel Data Specialist).

## 🚀 Live Demo & Deployment
- **Live Site**: Deployable to [Vercel](https://vercel.com)
- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS + Glassmorphism
- **Animations**: Framer Motion + 60fps HTML5 Canvas Particle Engine
- **Audio Synth**: Web Audio API UI Sound FX Engine

## 🛠️ Stack & Technologies
- **Frontend**: React.js, Tailwind CSS, Framer Motion, Lucide Icons, Vite
- **Backend Skills**: Node.js, Express.js, MongoDB, RESTful APIs, JWT Auth
- **Design & Office Tools**: Canva Graphic Design, MS Excel Formulas & Data Entry, Figma
- **Mobile**: Flutter

## 💻 Local Setup & Development

```bash
# 1. Install dependencies
npm install

# 2. Run development server
npm run dev

# 3. Build production bundle
npm run build
```
